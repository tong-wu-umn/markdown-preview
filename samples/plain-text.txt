# Plain-text sample

This file has a `.txt` extension. Markdown Preview renders `.txt` files as
Markdown, so the heading above, the list below, and the link all render.

## Things to check

- The heading and this list render as Markdown, not as raw text.
- *Italic*, **bold**, and `code` spans render too.
- The link opens in the app: [full feature sample](full.md)
- This file shows up in the Project Navigator unless *Settings → General →
  Show plain-text files in navigator* is off.

## Hard-wrapped prose

Lines in this paragraph are hard-wrapped at about 72 columns, as plain-text
notes often are. Rendered as Markdown, they reflow into a single paragraph.
